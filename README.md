# 🎵 Spotify Clone (HTML & CSS)

This is a static **Spotify clone website** built using only **HTML** and **CSS**. It replicates the design and layout of Spotify’s web player interface as a beginner-friendly project to practice front-end development skills.

---

## 🚀 Features

- 🎧 Spotify-like homepage layout
- 🎵 Song list / playlist section UI
- 🖼️ Sidebar with logo, navigation menu
- ▶️ Play bar design at the bottom
- ✨ Hover effects and polished layout

> ⚠️ This version is not responsive — best viewed on desktop screens.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox & Grid)
